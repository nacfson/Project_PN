Security Boundaries

  • Content script never stores the JWT.
  • Background worker is the only component that talks to the backend.
  • Popup only renders UI and triggers auth.
  • Extension uses activeTab, not <all_urls>.

2. Auth Flow Sequence

sequenceDiagram autonumber actor U as User participant P as Extension Popup participant L as Project PN Login Page participant A as Auth API participant B as Background Worker participant S as chrome.storage.local U->>P: Clicks extension icon P->>P: No token found P->>U: Shows "Sign in" button U->>P: Clicks sign in P->>L: Opens /login?extension=1 U->>L: Enters email + password L->>A: POST /api/auth/session A-->>L: JWT token L->>L: Detects chrome.runtime L->>P: sendMessage(token) P->>S: setToken(token) P->>U: Shows signed-in state + default deck
The login page uses externally_connectable to send the token back to the extension only after a successful login.

3. Add Word Flow Sequence

sequenceDiagram autonumber actor U as User participant W as Webpage participant C as Content Script participant M as Context Menu participant B as Background Worker participant S as chrome.storage.local participant V as Vocab API U->>W: Selects word U->>M: Right-clicks M->>M: Shows "Add '{word}' to Project PN" U->>M: Clicks item M->>B: onClicked(info) B->>C: request selected text C-->>B: trimmed word B->>S: getToken() S-->>B: JWT B->>V: POST /api/words/lookup V-->>B: SenseOption[] B->>B: Pick SenseOption[0] B->>S: getDefaultDeckId() S-->>B: deckId B->>V: POST /api/learning-items V-->>B: success B->>C: showInlineToast("Added '{word}'") C->>U: Toast appears near selection
If the user is not signed in, the background worker opens the login popup instead of calling the vocab API.

5. Permission Manifest (MV3)

{
  "manifest_version": 3,
  "name": "Project PN",
  "permissions": ["contextMenus", "activeTab", "storage", "scripting"],
  "host_permissions": [],
  "externally_connectable": {
    "matches": ["https://app.projectpn.com/*"]
  },
  "background": { "service_worker": "background.js" },
  "content_scripts": [
    { "matches": ["<all_urls>"], "js": ["content.js"], "run_at": "document_end" }
  ],
  "action": { "default_popup": "popup.html" }
}
content_scripts.matches uses <all_urls> so the context menu can read selection anywhere, but the script does nothing until the background worker requests text.
