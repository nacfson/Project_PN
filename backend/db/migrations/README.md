# backend/db/migrations

## Overview
Ordered `golang-migrate` PostgreSQL schema and data migrations (`000001` through `000030`, each with `.up.sql` and `.down.sql` pairs) defining Project PN's relational data model. The schema separates global dictionary data (`words`, `word_senses`, `sense_translations`, `examples`, `example_translations`) from per-user learning progress (`user_word_senses`, `user_personal_meanings`, `review_states`, `review_attempts`, `review_settings`, `daily_review_counts`, `user_streaks`, `decks`, `user_languages`), push notifications (`device_push_tokens`, `notification_sends`), and Keycloak/gateway platform identity bindings (`users`, `user_identities`, `account_merge_requests`).

## Interface
- Extension `pgcrypto` `[000001_init_mvp_schema.up.sql:pgcrypto]` — Provides `gen_random_uuid()` for UUID primary keys across all tables.
- Table `users` `[000001_init_mvp_schema.up.sql:users]`, `[000003_auth.up.sql:users]`, `[000014_user_languages.up.sql:users]`, `[000017_drop_dead_auth.up.sql:users]` — User accounts (`id`, `email`, `native_language`, `target_language`, `email_verified_at`, `ui_language` default `'en'`, `created_at`, `updated_at`); unique case-insensitive index `users_email_lower_idx` on `lower(email)`. (`password_hash` added in `000003` was dropped in `000017`.)
- Table `user_identities` `[000016_user_identities.up.sql:user_identities]`, `[000023_integrated_accounts.up.sql:user_identities]`, `[000028_drop_account_link_requests.up.sql:user_identities]`, `[000029_platform_identity_bindings.up.sql:user_identities]` — External identity bindings (`id`, `user_id`, nullable legacy `provider`/`provider_subject`, `email_at_provider`, `linked_at`, `issuer`, `subject`, `sign_in_method`); unique constraint `user_identities_issuer_subject_unique` on `(issuer, subject)`, partial unique index `user_identities_one_google_per_user` on `(user_id) WHERE provider = 'google'`, and `user_identities_user_id_idx`.
- Table `account_merge_requests` `[000023_integrated_accounts.up.sql:account_merge_requests]` — Pending/completed/cancelled account merges (`id`, `source_user_id`, `target_user_id`, `initiated_by_user_id`, `status`, `source_email`, `target_email`, `expires_at`, `completed_at`, `created_at`) with `account_merge_requests_target_status_idx`.
- Table `user_languages` `[000014_user_languages.up.sql:user_languages]`, `[000018_user_languages_perf_idx.up.sql:user_languages_user_id_created_at_idx]` — Per-user target/display language pairs (`user_id`, `target_language`, `display_language`, `is_active`, `created_at`, `updated_at`), PK `(user_id, target_language)`, partial unique index `user_languages_active_unique` on `(user_id) WHERE is_active = true`, `user_languages_user_id_idx`, and `user_languages_user_id_created_at_idx`.
- Table `decks` `[000015_decks.up.sql:decks]`, `[000022_drop_curriculum.up.sql:decks]` — User vocabulary decks per target language (`id`, `user_id`, `target_language`, `name`, `is_default`, `created_at`, `updated_at`); unique indexes `decks_user_target_default_unique` (`WHERE is_default = true`) and `decks_user_target_name_unique` on `(user_id, target_language, lower(name))`, plus `decks_user_id_idx` and `decks_user_target_idx`.
- Table `words` `[000001_init_mvp_schema.up.sql:words]`, `[000005_words_prefix_search.up.sql:words_normalized_text_prefix_idx]` — Global dictionary lemmas (`id`, `language_code`, `lemma`, `normalized_text`, `part_of_speech`, `pronunciation`, `audio_url`, `created_at`, `updated_at`); unique constraint `words_identity_unique` on `(language_code, normalized_text, part_of_speech)` and prefix index `words_normalized_text_prefix_idx` (`text_pattern_ops`).
- Table `word_senses` `[000001_init_mvp_schema.up.sql:word_senses]`, `[000006_multilang_translations.up.sql:word_senses]` — Ordered meanings per word (`id`, `word_id`, `definition`, `short_definition`, `cefr_level`, `meaning_order`, `created_at`, `updated_at`); unique constraint `word_senses_order_unique` on `(word_id, meaning_order)`.
- Table `sense_translations` `[000006_multilang_translations.up.sql:sense_translations]` — Localized sense definitions (`id`, `word_sense_id`, `language_code`, `definition`, `short_definition`, `created_at`, `updated_at`); unique `(word_sense_id, language_code)` and `sense_translations_sense_lang_idx`.
- Table `examples` `[000001_init_mvp_schema.up.sql:examples]`, `[000006_multilang_translations.up.sql:examples]`, `[000019_one_example_per_sense.up.sql:examples_one_per_sense_uidx]` — Example sentences per sense (`id`, `word_sense_id`, `sentence`, `source`, `difficulty_level`, `cloze_text`, `cloze_answer`, `created_at`, `updated_at`); indexes `examples_word_sense_id_idx` and unique `examples_one_per_sense_uidx` on `(word_sense_id)`.
- Table `example_translations` `[000006_multilang_translations.up.sql:example_translations]` — Localized example translations (`id`, `example_id`, `language_code`, `translation`, `created_at`, `updated_at`); unique `(example_id, language_code)` and `example_translations_example_lang_idx`.
- Table `user_word_senses` `[000001_init_mvp_schema.up.sql:user_word_senses]`, `[000004_learning_items_list_index.up.sql:user_word_senses_active_user_added_idx]`, `[000015_decks.up.sql:user_word_senses]`, `[000030_user_personal_meanings.up.sql:user_word_senses]` — Core learnable unit (`id`, `user_id`, nullable `word_sense_id`, `deck_id`, `learning_stage`, `source_context`, deprecated legacy `personal_note`, `difficulty_rating`, `added_at`, `archived_at`, `created_at`, `updated_at`); unique `(user_id, word_sense_id)`, FK `user_word_senses_deck_id_fk` (`ON DELETE RESTRICT`), partial index `user_word_senses_active_user_added_idx` (`WHERE archived_at IS NULL`), and `user_word_senses_deck_id_idx`.
- Table `user_personal_meanings` `[000030_user_personal_meanings.up.sql:user_personal_meanings]` — User-private 5-column gloss and custom-card table (`user_word_sense_id` PK referencing `user_word_senses(id) on delete cascade`, nullable `lemma`, nullable `part_of_speech`, non-blank `meaning`, `updated_at`), with `user_personal_meanings_custom_pair_valid` enforcing that `lemma` and `part_of_speech` are either both `NULL` (dictionary card override) or both non-blank (custom card).
- Table `review_states` `[000001_init_mvp_schema.up.sql:review_states]`, `[000008_add_fsrs_review_state.up.sql:review_states]`, `[000009_anki_step_logic.up.sql:review_states]` — One-to-one FSRS/Anki scheduling state per `user_word_sense_id` (`due_at`, `interval_days`, `ease_factor`, `last_reviewed_at`, `review_count`, `lapse_count`, `fsrs_state`, `stability`, `difficulty`, `scheduled_days`, `remaining_steps`, `buried_until`, `is_suspended`, `created_at`, `updated_at`); unique `(user_word_sense_id)` and `review_states_due_at_idx`.
- Table `review_attempts` `[000001_init_mvp_schema.up.sql:review_attempts]`, `[000007_add_review_attempts_rating_score.up.sql:review_attempts]` — Append-only review history (`id`, `user_word_sense_id`, `activity_type`, `prompt`, `user_answer`, `correct_answer`, `is_correct`, `review_rating`, `rating_score` default `2.0`, `response_time_ms`, `confidence_rating`, `metadata`, `reviewed_at`, `created_at`); index `review_attempts_user_word_sense_reviewed_at_idx`.
- Table `review_settings` `[000009_anki_step_logic.up.sql:review_settings]`, `[000010_fsrs_optimization.up.sql:review_settings]`, `[000011_user_streaks_daily_goal.up.sql:review_settings]`, `[000027_leech_action_default_tag.up.sql:review_settings]` — Per-user scheduler config (`user_id`, `new_cards_per_day`, `reviews_per_day`, `learning_steps`, `relearning_steps`, `leech_threshold`, `leech_action` default `'tag'`, `fuzz_enabled`, `desired_retention`, 19-element `fsrs_weights`, `weights_optimized_at`, `weights_review_count`, `daily_goal_xp`); unique `(user_id)` and `review_settings_user_id_idx`.
- Table `daily_review_counts` `[000009_anki_step_logic.up.sql:daily_review_counts]` — Per-day quota counters (`id`, `user_id`, `review_date`, `new_cards_done`, `reviews_done`); unique `(user_id, review_date)` and `daily_review_counts_user_date_idx`.
- Table `user_streaks` `[000011_user_streaks_daily_goal.up.sql:user_streaks]` — Per-user streak state (`user_id`, `current_streak_days`, `longest_streak_days`, `last_review_date`, `streak_freeze_tokens`, `vacation_mode_until`); unique `(user_id)` and `user_streaks_user_id_idx`.
- Tables `device_push_tokens` & `notification_sends` `[000012_push_notifications.up.sql:device_push_tokens]`, `[000012_push_notifications.up.sql:notification_sends]` — Expo push token registry (`unique (user_id, token)`, `device_push_tokens_user_id_idx`) and sent notification log (`notification_sends_user_sent_at_idx`).
- Retired/dropped tables across history: `magic_link_tokens` and `magic_login_exchanges` (added `000003`, dropped `000013`), `sessions` and `email_verification_tokens` (dropped `000017`), `curriculum_packs`, `curriculum_pack_entries`, and `user_curriculum_enrollments` (added `000020`, seeded `000021`, dropped `000022`), and `account_link_requests` (added `000024`, dropped `000028`).

## Invariants
- Emails are globally unique case-insensitively (`users_email_lower_idx` on `lower(email)`) `[000003_auth.up.sql:users_email_lower_idx]`.
- Platform identities are globally unique by `(issuer, subject)` with `issuer`, `subject`, and `sign_in_method` all `NOT NULL` and `sign_in_method IN ('google', 'apple', 'email')` `[000029_platform_identity_bindings.up.sql:user_identities_issuer_subject_unique]`, `[000029_platform_identity_bindings.up.sql:user_identities_sign_in_method_check]`.
- `account_merge_requests` enforces `source_user_id <> target_user_id` and `status IN ('pending', 'completed', 'cancelled')` `[000023_integrated_accounts.up.sql:account_merge_requests_distinct_users]`.
- Each user has at most one active learning language (`user_languages_active_unique` `WHERE is_active = true`) and at most one default deck per `(user_id, target_language)` (`decks_user_target_default_unique`), with deck names unique case-insensitively per `(user_id, target_language)` `[000014_user_languages.up.sql:user_languages_active_unique]`, `[000015_decks.up.sql:decks_user_target_default_unique]`, `[000015_decks.up.sql:decks_user_target_name_unique]`.
- Global dictionary uniqueness is `(language_code, normalized_text, part_of_speech)` on `words`, `(word_id, meaning_order)` with `meaning_order > 0` and CEFR in `A1..C2` on `word_senses`, and at most one example per sense (`examples_one_per_sense_uidx`) with `difficulty_level IN ('easy', 'medium', 'hard')` `[000001_init_mvp_schema.up.sql:words_identity_unique]`, `[000006_multilang_translations.up.sql:word_senses_order_unique]`, `[000019_one_example_per_sense.up.sql:examples_one_per_sense_uidx]`.
- Every `user_word_senses` row must belong to a non-null `deck_id` (`ON DELETE RESTRICT`), is unique per `(user_id, word_sense_id)` when `word_sense_id IS NOT NULL`, constrains `learning_stage` to `('new', 'learning', 'recognized', 'recalled', 'usable', 'mastered', 'archived')`, and constrains `difficulty_rating` to `1..5` `[000001_init_mvp_schema.up.sql:user_word_senses]`, `[000015_decks.up.sql:user_word_senses_deck_id_fk]`, `[000030_user_personal_meanings.up.sql:user_word_senses]`.
- `user_personal_meanings` requires non-blank `btrim(meaning) <> ''` and enforces strict paired `lemma`/`part_of_speech` nullability via `user_personal_meanings_custom_pair_valid` `[000030_user_personal_meanings.up.sql:user_personal_meanings]`.
- `review_states` is 1:1 with `user_word_senses` and enforces `fsrs_state IN ('New', 'Learning', 'Review', 'Relearning')`, `ease_factor >= 1.00`, and non-negative `interval_days`, `review_count`, `lapse_count`, `stability`, `difficulty`, `scheduled_days`, and `remaining_steps` `[000001_init_mvp_schema.up.sql:review_states]`, `[000008_add_fsrs_review_state.up.sql:review_states_fsrs_state_valid]`.
- `review_attempts` constrains `activity_type` to the 8 supported modes, `review_rating` to `('again', 'hard', 'good', 'easy')`, `response_time_ms >= 0`, and `confidence_rating` to `1..5` `[000001_init_mvp_schema.up.sql:review_attempts]`.
- `review_settings` enforces `leech_action IN ('suspend', 'tag')` (default `'tag'`), `desired_retention BETWEEN 0.7 AND 0.99`, `new_cards_per_day >= 0`, `reviews_per_day >= 0`, `leech_threshold >= 1`, and `daily_goal_xp >= 10` `[000009_anki_step_logic.up.sql:review_settings]`, `[000011_user_streaks_daily_goal.up.sql:review_settings_daily_goal_positive]`, `[000027_leech_action_default_tag.up.sql:review_settings]`.
- `user_streaks` enforces non-negative `current_streak_days`, `longest_streak_days`, and `streak_freeze_tokens`; `device_push_tokens` enforces `platform IN ('ios', 'android', 'web')` `[000011_user_streaks_daily_goal.up.sql:user_streaks]`, `[000012_push_notifications.up.sql:device_push_tokens]`.
- `000006_multilang_translations.up.sql` aborts with a PL/pgSQL exception if duplicate `(word_id, meaning_order)` rows exist across definition languages `[000006_multilang_translations.up.sql:word_senses]`.

## Side Effects
- Executes DDL changes (creating/altering/dropping tables, constraints, indexes, and the `pgcrypto` extension) against the target PostgreSQL database `[000001_init_mvp_schema.up.sql:users]`, `[000029_platform_identity_bindings.up.sql:user_identities]`.
- Performs data seeding and backfills during forward migrations:
  - Seeds dev user `00000000-0000-0000-0000-000000000001` (`dev@project-pn.local`) `[000002_seed_dev_user.up.sql:users]`.
  - Backfills FSRS `fsrs_state`, `scheduled_days`, `stability`, and `difficulty` from legacy SM-2 columns `[000008_add_fsrs_review_state.up.sql:review_states]`.
  - Backfills `user_languages` and `users.ui_language` from existing `users` rows `[000014_user_languages.up.sql:user_languages]`.
  - Seeds default `decks` and backfills `user_word_senses.deck_id` (falling back to `'und (Default)'` if unmatched) `[000015_decks.up.sql:decks]`.
  - Destructively deletes extra examples per sense (keeping oldest by `created_at, id`) before creating `examples_one_per_sense_uidx` `[000019_one_example_per_sense.up.sql:examples]`.
  - Seeds Essential English A1 shared `words`, `word_senses`, and `examples` (pack metadata dropped in `000022`, while curriculum-deck `user_word_senses` are reassigned to each user's default private deck) `[000021_seed_essential_en_a1.up.sql:words]`, `[000022_drop_curriculum.up.sql:user_word_senses]`.
  - Retags multi-word `words` lemmas to `part_of_speech = 'phrase'` (one oldest row per `(language_code, normalized_text)`, non-reversible; `.down.sql` files are intentionally empty) `[000025_multiword_pos_to_phrase.up.sql:words]`, `[000026_multiword_pos_to_phrase_safe.up.sql:words]`.
  - Migrates existing `review_settings.leech_action = 'suspend'` rows to `'tag'` `[000027_leech_action_default_tag.up.sql:review_settings]`.
  - Backfills `user_identities.subject`, `sign_in_method`, and `issuer` (`https://auth.nacfson.cloud/realms/platform`) before adding `NOT NULL` constraints `[000029_platform_identity_bindings.up.sql:user_identities]`.
  - Creates `user_personal_meanings`, makes `user_word_senses.word_sense_id` nullable, and backfills existing non-blank `user_word_senses.personal_note` rows into `user_personal_meanings` `[000030_user_personal_meanings.up.sql:user_personal_meanings]`.
