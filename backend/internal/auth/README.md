# Auth

## Overview
Implements authentication verification, platform identity provisioning, ordinary learner capability modeling, user language management, and account merging for Project PN. Supports both local Keycloak JWKS JWT verification and internal platform gateway session-handle confirmation/exchange/logout, plus legacy central-auth compatibility helpers.

## Invariants
- `(*JWTVerifier).Verify` fails closed: rejects empty tokens, `alg: none` or algorithms outside `AllowedAlgs` (default `RS256`), ID tokens (`typ` header or payload `ID`/`ID_TOKEN`), invalid issuer/audience/expiry (with `ClockSkew`, default `1m`), missing `sub`, or unavailable JWKS `[jwt_verifier.go:Verify]`, `[jwt_verifier.go:NewJWTVerifier]`.
- `(*Service).EnsurePlatformUser` guards against typed-nil `*pgxpool.Pool` interfaces, resolves and provisions users strictly by `(issuer, subject)` without same-email auto-linking, synthesizes `<local>+<sub8>@platform.project-pn.local` on unique email conflict, and retries at most once on pre-commit connection errors (`BEGIN` failure, `io.ErrUnexpectedEOF`, `io.EOF`, `net.ErrClosed`, `driver.ErrBadConn`, SQLSTATE `08*`) without ever retrying after commit `[platform_user.go:EnsurePlatformUser]`, `[platform_user.go:ensurePlatformUserTx]`, `[retry.go:retryOncePreCommit]`, `[retry.go:isPreCommitConnError]`.
- `NewOrdinaryRole` fails closed with `ErrEmptyCapabilities` on an empty capability slice; nil `OrdinaryRole` denies all capabilities `[ordinary_role.go:NewOrdinaryRole]`, `[ordinary_role.go:Allows]`.
- `(*GatewayClient).ConfirmIdentity`, `ConfirmSessionHandle`, and `ExchangeTicket` require `signInMode == "shared"` (`SignInShared`), require `v1.` prefix for session handles, enforce expected project audience (`project-pn` for `pn.*` hosts), and reject expired JWT payloads or mismatched subjects `[gateway_client.go:ConfirmIdentity]`, `[gateway_client.go:ConfirmSessionHandle]`, `[gateway_client.go:ExchangeTicket]`, `[gateway_client.go:parseConfirmedIdentityResponse]`.
- `(*GatewayClient).LogoutSessionHandle` succeeds only when the gateway returns HTTP `200 OK` with `{"status":"revoked"}` `[gateway_client.go:LogoutSessionHandle]`.
- Language codes must match `^[a-z]{2,3}$` and any configured allowlist unless overridden by forced language settings; `RemoveUserLanguage` automatically activates the oldest remaining language pair when removing the active pair `[language.go:validateLanguageCode]`, `[service.go:resolveTargetLang]`, `[service.go:RemoveUserLanguage]`.
- `CreateMergeRequest` rejects self-merges and expires requests after 24 hours; `ConfirmMergeRequest` atomically deduplicates conflicting rows (`user_word_senses`, `user_languages`, `review_settings`), reassigns owned rows to `targetUserID`, moves non-conflicting `user_identities`, deletes the source user, and marks the request `completed` `[merge.go:CreateMergeRequest]`, `[merge.go:ConfirmMergeRequest]`, `[merge.go:mergeUsersTx]`.

## Side Effects
- Reads and mutates PostgreSQL tables `users`, `user_identities`, `user_languages`, `account_merge_requests`, and (during account merges) `user_word_senses`, `decks`, `daily_review_counts`, `user_streaks`, and `review_settings` `[platform_user.go:ensurePlatformUserTx]`, `[central_user.go:EnsureCentralUser]`, `[service.go:AddUserLanguage]`, `[merge.go:mergeUsersTx]`.
- Performs outbound HTTP requests to the JWKS URL (`jwk.Fetch`), internal platform gateway (`GET /auth`, `POST /auth/exchange`, `POST /auth/logout`), and legacy central-auth endpoints (`/api/auth/session`, `/api/internal/cookie-session`, `/api/auth/refresh`) `[jwt_verifier.go:FetchJWKS]`, `[gateway_client.go:ConfirmSessionHandle]`, `[gateway_client.go:ExchangeTicket]`, `[gateway_client.go:LogoutSessionHandle]`, `[central_client.go:ValidateSession]`.
- Caches fetched `jwk.Set` in memory under `JWTVerifier.jwksMu` `[jwt_verifier.go:FetchJWKS]`.
