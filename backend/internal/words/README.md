# Words

## Overview
Core vocabulary-learning domain service for Project PN. Manages the global dictionary cache (`words`, `word_senses`, `sense_translations`, `examples`, `example_translations`), personal learnable units (`user_word_senses`, `user_personal_meanings`, `review_states`, append-only `review_attempts`), FSRS v4 spaced-repetition scheduling and weight optimization, decks, streaks, aggregate stats, Anki CSV preview/import, re-engagement push notification candidate evaluation, content discovery, and sense retranslation/remapping.

## Invariants
- Global dictionary rows (`words`, `word_senses`, `sense_translations`, `examples`) remain strictly separated from personal state (`user_word_senses`, `user_personal_meanings`, `review_states`, `review_attempts`); `SetPersonalNote`, `AddManualLearningItem`, and unmatched/override Anki CSV imports write personal wording exclusively to `user_personal_meanings` (never modifying global dictionary tables) and `SetPersonalNote` rejects blank meanings on custom cards with `ErrPersonalNoteRequired` `[service.go:SetPersonalNote]`, `[service.go:AddManualLearningItem]`, `[import_service.go:ImportAnkiCards]`.
- `AddLearningItem` and `ChangeLearningItemSense` refuse to add/swap to a sense whose display language differs from the word language unless a `sense_translations` row exists (`ErrTranslationUnavailable`, unless a `personal_note` override is provided); `ChangeLearningItemSense` preserves `review_states`, supports upgrading custom cards (`word_sense_id is null`) onto matching dictionary senses, and forbids cross-word/mismatched-lemma swaps (`ErrSenseWrongWord`) or active duplicate senses (`ErrSenseConflict`) `[service.go:AddLearningItem]`, `[service.go:ChangeLearningItemSense]`.
- `ForceGenerate` requires a concrete `part_of_speech` (not empty/`"any"`) or a `word_id` (`ErrForceAmbiguous`), filters candidates via `enrich.FilterProperSenses`, and returns `ErrNoAdditionalSense` if no distinct sense survives `[service.go:ForceGenerate]`, `[service.go:forceUnderWord]`.
- `GetDueReviewItems` fetches unfinished intra-day `Learning`/`Relearning` cards first without daily quota or `due_at <= now()` gating, then `Review` cards up to remaining `reviews_per_day`, then `New` cards up to remaining `new_cards_per_day`, and shuffles + round-robin interleaves by normalized lemma key (`language_code:normalized_text`, falling back to `WordID` then `UserWordSenseID`) within review-like and new groups `[service.go:GetDueReviewItems]`, `[due_queue.go:shuffleAndInterleaveDueItems]`, `[due_queue.go:interleaveDueItems]`.
- `RecordBatchReviewAttempts` executes atomically in a PostgreSQL transaction: rejects archived/suspended/foreign cards (`ErrReviewItemUnavailable`), appends to `review_attempts`, updates `review_states` and `daily_review_counts`, buries sibling senses and custom cards sharing `(target_language, normalized_lemma)` until 23:59:59 UTC, archives/suspends leeches when `lapse_count >= leech_threshold` and `leech_action == "suspend"`, updates `user_streaks`, and flushes learning-log lines only after commit `[batch_reviews.go:RecordBatchReviewAttempts]`.
- `PreviewIntervals` disables fuzz (`FuzzEnabled = false`) so button previews stay deterministic and monotonic; `UpdateReviewSettings` clamps `desired_retention` to `[0.80, 0.95]` and `daily_goal_xp` to `[10, 1000]` `[scheduler.go:PreviewIntervals]`, `[service.go:clampDesiredRetention]`, `[streak.go:clampDailyGoalXP]`.
- `OptimizeWeights` requires at least `MinReviewsForOptimization` (`1000`) review records before updating `review_settings.fsrs_weights` `[fsrs_optimizer.go:OptimizeWeights]`.
- `DeleteDeck` forbids deleting default decks (`ErrCannotDeleteDefaultDeck`) and reassigns all items to the language's default deck before deletion; `MoveItemsToDeck` requires every item to belong to the user and match the deck's `target_language` (`ErrDeckLanguageMismatch`) `[deck.go:DeleteDeck]`, `[deck.go:MoveItemsToDeck]`.
- `BuildNotificationCandidates` enforces a 4-hour send backoff (`notificationBackoff`), ±1h preferred UTC review hour window, and prioritizes `due_review` over `words_slipping` (retrievability `< 0.70`) `[notifications.go:BuildNotificationCandidates]`, `[notifications.go:buildUserNotificationCandidate]`.
- `RetranslateWord` is resume-safe: enrichment runs before opening the DB transaction so failures leave existing senses untouched, and remapping resolves `(user_id, new_sense_id)` collisions by keeping the card with highest `ReviewCount` (tie-break earliest `AddedAt`) `[retranslate.go:RetranslateWord]`, `[retranslate.go:remapUserWordSenses]`, `[retranslate.go:pickRemapWinner]`.

## Side Effects
- Reads and mutates PostgreSQL tables `words`, `word_senses`, `sense_translations`, `examples`, `example_translations`, `user_word_senses`, `user_personal_meanings`, `review_states`, `review_attempts`, `review_settings`, `daily_review_counts`, `decks`, `user_languages`, `users`, `user_streaks`, `device_push_tokens`, and `notification_sends` `[service.go:persistEntries]`, `[service.go:AddManualLearningItem]`, `[batch_reviews.go:RecordBatchReviewAttempts]`, `[deck.go:DeleteDeck]`, `[streak.go:applyStreakReview]`, `[notifications.go:RegisterPushToken]`.
- Calls the configured `enrich.Enricher` (`Enrich` and `Translate`) on cache misses, forced generation, missing display translations, Anki imports, and retranslations (with a 40s detached timeout on `Lookup`) `[service.go:Lookup]`, `[service.go:ensureWordTranslations]`, `[retranslate.go:RetranslateWord]`.
- Emits structured audit lines to `admin.Logger` (`ADD_WORD`, `ENRICH_FAIL`, `TRANSLATE_FAIL`, `RETRANSLATE`, `RETRANSLATE_MATCH`) and domain event rows to `learninglog.Logger` (`learning_item_added`, `review_attempted`, `sense_changed`, `learning_item_archived`, `personal_meaning_set`) `[service.go:persistEntries]`, `[batch_reviews.go:RecordBatchReviewAttempts]`, `[sense_log_snapshot.go:emitLearningItemAdded]`, `[sense_log_snapshot.go:emitManualLearningItemAdded]`, `[change_sense_log.go:emitSenseChanged]`.
