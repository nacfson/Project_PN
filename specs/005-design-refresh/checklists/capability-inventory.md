# Capability Inventory Checklist (005-design-refresh)

Mapping of every pre-redesign user-facing capability to its destination in the `005-design-refresh` UI (FR-036, SC-005).

- [X] **Today dashboard & due review count** → `TodayScreen` (`frontend/src/features/today/TodayScreen.tsx`): Hero card with due count (`CountUpText`), estimated minutes, and primary "Start review" CTA (`navigation.navigate('Review')`).
- [X] **Streak & daily goal progress** → `TodayScreen` (`frontend/src/features/today/TodayScreen.tsx`): 4-cell metrics strip (`Streak`, `Daily goal`, `Mastered`, `Total words`) with tabular numerals.
- [X] **Mastery stage distribution breakdown** → `TodayScreen` (`frontend/src/features/today/TodayScreen.tsx`): `StageBar` 6-stage proportional bar (`New`, `Learning`, `Recognized`, `Recalled`, `Usable`, `Mastered`) + 6-item legend with counts.
- [X] **Up next due words preview** → `TodayScreen` (`frontend/src/features/today/TodayScreen.tsx`): Up next card showing up to 5 due items (`Newsreader` lemma, POS, `IBM Plex Sans KR` gloss, stage pill) + "See all in Words →" link.
- [X] **Focused flashcard review session** → `PracticeScreen` (`frontend/src/features/practice/PracticeScreen.tsx`): Full-screen focus mode (`setChromeHidden(true)`), `← End` exit control, correct-only `sessionProgress()` bar and `{current} of {total}` counter, `Flashcard` (`Newsreader` lemma, `Geist Mono` IPA, audio button, stage/Retrying/Stuck pill, gloss-only answer), 4-button `RatingBar` (`Forgot`/`Hard`/`Good`/`Easy` with `1`–`4` shortcuts and `Space` reveal).
- [X] **Session summary, Stuck words & Repeat review** → `PracticeScreen` (`frontend/src/features/practice/PracticeScreen.tsx`): Session complete view with `Confetti`, accuracy & duration stats, Stuck words list with `ChangeMeaningSheet` ("Change meaning" / "Write my meaning"), and "Practice again" repeat review action.
- [X] **Manual word or phrase lookup & add (Default Add mode)** → `AddScreen` (`frontend/src/navigation/AddScreen.tsx`) + `ManualAddSection` (`frontend/src/features/add/ManualAddSection.tsx`): Default `'manual'` segment ("Word or phrase") first in `SegmentedControl`, `Newsreader` display input, optional context sentence & personal meaning (`personal_note`), POS filter, and gloss-only `SensePicker`.
- [X] **Passage word & multi-word phrase capture** → `AddScreen` (`frontend/src/navigation/AddScreen.tsx`) + `CaptureSection` (`frontend/src/features/add/CaptureSection.tsx`): Second segment ("From a passage") with `TappablePassage` word/phrase selection, local undo on clear, and batch/single sense resolution.
- [X] **Anki `.apkg` / TSV import** → Reachable from `AddScreen` header "Import" action and `MyWordsScreen` header "Import" button → `AnkiImportScreen` (`frontend/src/features/import/AnkiImportScreen.tsx`) & `ImportConflictPicker` (`frontend/src/features/import/ImportConflictPicker.tsx`).
- [X] **Words library search, stage filtering & sorting** → `MyWordsScreen` (`frontend/src/features/words/MyWordsScreen.tsx`): `/` keyboard-focusable search input, stage filter chips with live counts (`All`, `New`, `Learning`, `Recognized`, `Recalled`, `Usable`, `Mastered`, `Stuck`), and sort picker (`Due soon`, `Recently added`, `A–Z`, `Stage`).
- [X] **Deck filtering & deck management (`DeckCanvas` / `DeckList`)** → `DeckFilterMenu` (`frontend/src/features/words/DeckFilterMenu.tsx`) in `MyWordsScreen` header filters by deck, opens `DeckFormModal` ("+ New deck…"), or navigates to `DecksScreen` (`frontend/src/features/words/DecksScreen.tsx` in `WordsStack`) which hosts `DeckCanvas` (desktop/web) and `DeckList` (mobile), plus `MoveToDeckModal` and practice-by-deck.
- [X] **Word detail, meaning change & guarded word removal** → `WordDetailScreen` (`frontend/src/features/words/WordDetailScreen.tsx`) and `MyWordsScreen` row/bulk actions: View/edit sense or `personal_note` via `ChangeMeaningSheet`, move between decks, and remove words guarded by `ConfirmDialog` ("Remove this word? This can't be undone.").
- [X] **Account, Language Pairs, Connected Accounts & Account Merge** → `ProfileScreen` (`frontend/src/features/profile/ProfileScreen.tsx`) Account group → `LanguagePairsScreen`, `AddLanguagePairScreen`, `EditLanguagePairScreen`, `ConnectedAccountsScreen`, and `AccountMergeScreen` in `SettingsStack`.
- [X] **Review settings (Daily goal, Retention target)** → `ProfileScreen` Review group: Optimistic `SegmentedControl` for daily goal (`100` / `200` / `300` / `500` XP) and retention slider (`70%`–`97%`).
- [X] **Streak settings (Vacation mode & Streak freeze)** → `ProfileScreen` Streak group: Vacation mode `Switch` and "Use a streak freeze" action.
- [X] **Appearance (App language `en` / `ko`)** → `ProfileScreen` Appearance group: Segmented control for `English` / `한국어` (`useAppLanguage()`), with light-only theme applied automatically.
