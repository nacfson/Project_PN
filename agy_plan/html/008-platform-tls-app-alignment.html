Spec 008 Platform TLS Termination — Project PN App Alignment

Source: nacfson_pipeline/specs/008-platform-tls-termination/handoff-project-pn.md (US2, FR-003, FR-011) · 2026-10-12

Summary

The platform terminates TLS for pn.nacfson.cloud at Traefik. PN pods receive plain HTTP. The audit found the app already complies, so no runtime behavior changes. The work is stale-doc cleanup plus one regression test for how the CSRF cookie's Secure flag is derived behind a TLS-terminating proxy.

Architecture

Dashed = plain HTTP inside the cluster (not encrypted). Traefik sets X-Forwarded-Proto: https and X-Forwarded-Host.
